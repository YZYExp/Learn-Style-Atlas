# 编辑约定

1. 写给非专业读者。新术语第一次出现，立即用日常语言解释。
2. 每章包含：小场景、插图、观察路径、方法原理、常见混淆、趣味练习、结果诚实评价。
3. 不以“好看”“高级”“治愈”代替分析。描述能在图上指认的线、面、边缘、颜色与空间。
4. 媒介、流派、视觉语言分别标明；章节归组只是阅读路线，不是互斥分类。
5. 所有生成插图标为教学示意。不得声称实际使用了颜料、刻刀、印刷机或严格像素网格。
6. 历史与真实工艺的外部事实附来源；本文的看图判断和学习比喻属于编辑解读。
7. 不将某幅图的特征推广为整个流派的必要条件；使用“本图”“常见”“一种路径”。
8. 人物可以跨年龄、职业与文化背景。图像质量不等于青春脸孔的精细程度。
9. 比较尽可能使用相近题材，并明确构图、角色和视角变化带来的干扰。
10. 插图采用稳定编号，不覆盖旧原图；新增版本用 `-v2` 等后缀，清单记录替换缘由。
11. 生成提示词有完整记录才标为原始提示；早期仅有简写时标为编辑摘要，不能冒充原文。
12. 书稿放在 `chapters/`；构建产物不手改。每次提交说明本次具体变化。

## v1.1 来源与交付规范

每个画风专题包含来源与发展；区分媒介历史、流派形成与现代传播，不能把品牌上市年等同于材料发明年。外部事实在句末或相关段落末标注来源编号并直链原始资料，附录说明支持范围；编辑观察与参考事实分开写。来源不支持的首创、统一起源、线性替代说法不补写。

名画和流行参考写明作品、作者或发布方与可核实背景。生成示例说明借用的方法、变化和干扰，不冒充参考原作。HTML 只保留用户可选命令，不自动生成、不纳入 Git 或交付包。
