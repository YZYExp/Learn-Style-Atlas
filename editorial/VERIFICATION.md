# v1.0 完本核验记录

全书定稿：2026-10-06。正文 51 个单元，加资料附录共 52 个阅读单元；35 个画风专题、35 张独立插图、14 组横向比较。合并稿含 34337 个汉字（含资料附录，不含英文与标点）。

## 已核验

- 正式目录覆盖全部分章与资料，顺序无重复；没有占位章节或第二卷承诺。
- 全部本地 Markdown 图片与文件链接存在，离线 HTML 的章节锚点唯一且均可到达。
- 35 张原始 PNG 的 SHA-256 与清单一致，阅读 JPEG 为实际图片。
- HTML 中 69 次图片引用逐一解码，并与阅读图字节校验值匹配，图片均有替代文字。
- 全部插图在生成结果中逐张观察，正文包含实际特征与偏离目标之处。
- 14 组比较与漫画案例明确标注题材、构图、细节变化带来的干扰。
- 20 个资料编号只用于相应外部事实；馆方作品旁读不复制外部图像。
- 目录筛选、明暗切换与图片放大脚本通过 JavaScript 语法检查。
- Git 保留既有提交，完整性检查通过，定稿标记为 v1.0；ZIP 收入完整历史和可重建产物。

## 阅读版的检查边界

HTML 为独立文件，图片内嵌，支持目录筛选、明暗切换与点击放大。已完成静态结构和字节完整性核验。当前环境没有可执行浏览器，未做真实浏览器截图检查，也未宣称完成桌面与手机的视觉回归测试。分章 Markdown 是权威书稿，阅读不依赖 HTML 脚本。

所有生成图都是视觉模拟，真实工艺不能由图像外观确认。这个边界在导读、材料章节、资料附录与各专题中明确说明。
