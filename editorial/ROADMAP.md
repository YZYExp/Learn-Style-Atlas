# 后续扩充路线

本文件是计划，不是未写完的正文目录。v0.1 已交付 16 个专题与完整前后篇。

## 第二卷：更多观看方式

- 工笔与写意的正面对照：同一枝花、同一只鸟，减少人物美化干扰。
- 印象主义、点彩与野兽派：把光、光学混色和非自然色分开讲；新增相同街角对照。
- 装饰艺术与新艺术：用建筑、服装和边框比较几何节奏与植物曲线。
- 铅笔、钢笔与蚀刻：展示线条为何会留下不同的痕迹。
- 剪纸、拼贴与剪影：讲形状、负空间和图层关系。
- 欧式清线漫画、美式漫画、韩式网络漫画：从叙事节奏而不只脸型切入。
- 粉彩、丙烯、蛋彩与数字喷绘：媒介效果需核实来源与真实作品。

## 第三卷：动手选风格

- 为同一个短故事做六种视觉方案。
- 同样构图的受控比较：每次只改一个观察维度。
- 角色之外：植物、动物、城市、静物与抽象形式。
- 真实作品旁读：补充博物馆原作链接与已核实的开放许可图片。

## 增补的完成条件

新增风格必须同时有独立插图、完整章节、误判说明、练习答案、来源记录和 Git 提交。没有插图的风格只留在路线图，不能计入已完成专题。

目前没有自动定时写作任务；后续会在继续对话时沿用该仓库与编号。
