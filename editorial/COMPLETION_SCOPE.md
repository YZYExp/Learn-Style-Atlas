# 全书范围与完稿标准

修订版本：v1.1。面向非专业读者的中文图解入门书，不是包罗全部历史流派的百科全书。

## 全书范围

35 个独立配图专题：既有 16 个方向；新增工笔、写意、印象主义、点彩、野兽派、装饰艺术、石墨铅笔、钢笔线描、蚀刻、剪纸、拼贴、剪影、色粉、丙烯、蛋彩、喷笔式渐变、清线漫画、美式动作漫画、纵向网络漫画。

观察方法、材料与外观、视觉维度、跨风格比较、三种漫画同故事案例、非人物题材、需求写作、学习路径、误判练习、词汇、原作旁读和结语全部写成正文。

## 完稿条件

- 35 个专题各有已生成且已观察的独立插图，正文含具体分析、常见误判、练习和结果评价。
- 相近题材组有明确的比较目标与干扰说明；漫画案例有完整故事与形式对照。
- 来源只支持直接可核实的外部事实；图像不能证明制作材料，必须标为视觉模拟。
- 所有正式目录项有正文；没有占位章节，没有以第二卷承诺代替内容。
- 清理全书中的待扩写、未来续写与旧版数量表述。旧路线图只归档作版本史。
- Markdown 为权威源；检查链接、图片、目录、Git 状态与压缩包。
- 53 个正文单元、43 张独立插图、40 个来源；35 个专题均有来源与发展，参考事实就近标注。
- 默认只构建 Markdown；HTML 仅保留用户自行执行的命令，产物不生成、不交付、不进入 Git。
- 保留原图与完整 Git 历史；验证压缩包解压后的仓库可正常读取。

## 为什么这个范围足以完本

全书目标是建立辨认、比较、选择与描述的能力。35 个样例覆盖线、面、透明与覆盖、笔触、颗粒、印刷、装饰、形变、空间、数字构形和连续叙事。没有承诺穷尽所有名称；结语结束学习循环，而非宣布另一部未写完的书。
