# 画风侦探的十个误区

下面每一句都听起来熟悉。先判断它是否可靠，再看后面的修正。它们没有要求你相信某张图更好，只帮助你把理由说得更准确。

| 常见说法 | 更可靠的修正 |
| --- | --- |
| 有纸纹就是水彩 | 纸纹可模拟；还要看透明叠色、留白与边缘 |
| 黑白就是素描 | 黑白也可能是版画、墨线、摄影或数字图形 |
| 点越多越像点彩 | 点应参与构形与色彩组织，随机噪声不够 |
| 粗线就是动作漫画 | 镜头、明暗、动态与分格同样重要 |
| 色彩鲜艳就是野兽派 | 非自然色与画面关系更有解释力；鲜艳本身不够 |
| 奇怪东西就是超现实主义 | 要看对象关系与观看逻辑，不能只靠怪物或装饰 |
| 几何图形就是立体主义 | 还要看形体重组、视点与空间问题 |
| 平滑就没有画风 | 平滑也是处理选择，体积和边缘仍需组织 |
| 细节越多越好 | 信息密度应服务于焦点、阅读尺度与目的 |
| AI 提示写了名字就成功 | 名字是目标；结果要回到图像核对 |

## 三个案件，试着独立判断

**案件一：**图像有古纸、花鸟和一段不可读题字，但轮廓模糊、羽毛只是一片通用毛纹。你能确认工笔吗？

**参考判断：**不能。题材与古纸属于气氛线索，缺少细致控制形色的证据。也不能因此直接确认写意；要继续看笔痕是否有组织。

**案件二：**画面由小圆点覆盖，但圆点下面仍有完整的平滑照片。它与本书点彩街景的关注点有什么不同？

**参考判断：**前者可能主要是表面滤镜，后者尝试用点形成形与色。这里说的是构形责任；实际混合方法仍可存在，不能只凭有底图就断定作品没有价值。

**案件三：**一张港口黑白图有细排线和矩形框。作者没写材料。你准备如何介绍？

**参考判断：**“它呈现细线排调与版画感，可能借鉴蚀刻外观；材料尚不能确认。”谨慎不是没有意见，而是让结论力度与证据匹配。

## 把“喜欢”与“成功”分开

你可以更喜欢偏离目标的图。例如清线方向生成图带丰富材质，你恰好喜欢那些石墙与雨痕。它在你的审美上成功，不代表它严格兑现了清线设想。这两种评价可以同时存在。

还可以把第三件事分开：用途。你喜欢细密拼贴，但它缩成很小的头像可能难读；你不太喜欢剪影，但它可能适合一眼识别的标识。审美、风格兑现程度与应用效果，不是同一张成绩单。
