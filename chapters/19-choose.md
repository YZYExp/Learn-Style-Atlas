# 给你的故事选一种画法

想象你正在为一家小书店做封面。故事是：店主骑车，把一本书送给住在海边的朋友。你要选什么画风？没有唯一答案，但可以先决定读者应当感受到什么。

## 从任务出发

| 你希望突出什么 | 可以先试的方向 | 还要检查什么 |
| --- | --- | --- |
| 轻盈、私人记录、旅行心情 | 水彩、彩铅 | 小尺寸下人物是否仍清楚 |
| 阳光、形状、色块节奏 | Gouache、Riso 风 | 色块是否过碎，是否真的需要分版 |
| 明快表情、连续动作、角色识别 | 赛璐璐式、漫画语言 | 线与阴影在多张图里能否一致 |
| 风浪、力量、明确剪影 | 黑白木刻风 | 细线缩小后会不会糊成黑块 |
| 人物经验与光影 | 炭笔、油画式 | 细节是否平均铺满、焦点是否明确 |
| 装饰性、收藏感、统一图案 | 新艺术启发 | 边框是否压住内容，曲线是否呼应 |
| 主观情绪、强烈节奏 | 表现主义启发 | 形变与颜色是否服务于情绪 |
| 多视点、分析与重组 | 立体主义启发 | 对象仍有多少识别线索 |
| 谜、梦与意外联想 | 超现实主义启发 | 不可能关系是否清楚，是否只堆奇怪道具 |
| 游戏联想、离散构形 | 像素艺术 | 是否真正遵守网格和缩放规则 |
| 花鸟的精细结构与疏朗空间 | 工笔淡彩 | 细节是否解释羽片、花瓣与叶脉 |
| 简练笔痕与生长的气息 | 写意淡彩 | 简化是否仍有结构，是否只剩随意涂抹 |
| 街头的光与瞬间感觉 | 印象主义启发 | 色彩是否表达光照，而非只有模糊 |
| 近远尺度变化与色点节奏 | 点彩 | 点是否承担构形，缩小后是否仍清楚 |
| 独立大胆的色面关系 | 野兽派启发 | 非自然色是否有秩序，是否仅加饱和度 |
| 几何装饰、放射与阶梯秩序 | 装饰艺术方向 | 装饰是否抢走主体和标题位置 |
| 港口、建筑与线调观察 | 石墨、墨线、蚀刻风 | 连续灰面和细线的分工；不要误认真实工艺 |
| 纸层的手作感、材料的相遇 | 剪纸拼贴、混合拼贴 | 接缝、遮挡和纹样是否有主次 |
| 快速识别与清楚形状 | 剪影 | 耳、嘴、把手等外缘线索是否足够 |
| 静物的触感与光 | 色粉、丙烯、蛋彩、喷笔方向 | 先选颗粒、块面、细痕或渐变，再决定材料 |
| 易读日常、动作强度或滚动节奏 | 清线、动作漫画、纵向漫画方向 | 镜头、黑白强度和空隙是否支持同一故事 |

这是针对本书示例的尝试顺序，不是给流派规定用途。同一种风格可以讲很多故事。

## 让选风格变成一个小实验

先用文字写三个版本：水彩版把送书过程画成轻薄旅行记录；木刻版把店主与风浪的剪影放大；超现实版让书页折成通向远方的楼梯。题材相同，观看重点已经不同。

接着只选择一个版本，问三个问题：人物是不是主角？背景承担信息还是气氛？图像主要在手机上看，还是会放大印出来？回答比堆十个风格名字更有用。

## 混合也要有主次

“新艺术构图 + 彩铅人物”可以成立：前者控制曲线、边框和整体节奏，后者控制局部表面。但若同时要求透明水彩留白、厚涂油画堆积、全图严格像素和精细摄影皮肤，局部规则可能互相冲突。

你可以先指定主导层次：整体构图用什么，人物造型用什么，明暗怎样组织，表面保留什么痕迹。必要时限制不同方法使用的区域。

## 小尺寸是另一场考试

把封面缩成聊天头像大小，检查眼神、轮廓和主要色块是否仍然成立。插图的细腻不等于信息清楚。文字留白和人物细节也要一起规划，不能画完后再硬塞标题。

**练习答案示例：**如果任务是书店的小海报，可以先选 Riso 风的少量颜色与块面节奏，再简化书本细节。若是私人纪念册，彩铅的近景人物可能更合适。选择依据来自用途和情绪，不来自所谓高级程度。
