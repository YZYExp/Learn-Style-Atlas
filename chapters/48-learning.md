# 七次轻松练习：把这本书变成自己的观看能力

不需要买画材，也不用每天交作业。每次十五到三十分钟，用纸、手机或文字就能完成。七次之后，你会留下七张小记录，比记住三十五个名字更实用。

## 第一次：只写看见的

选透明水彩图。先写五句可观察事实，例如“头发边缘有些位置融进背景”。暂时不用“高级”“治愈”“梦幻”。再写一句感受，把感受与事实连起来。

**自查：**别人能在图上找到你说的位置吗？若找不到，把范围缩小。观察不必很复杂，但要有落点。

## 第二次：同题材比较

选工笔和写意麻雀，只比较轮廓、羽毛与空白。分别写一件共同点和两件差异。

**自查：**共同点可以是题材相同，差异要落到方法。不要把“后一张比较潇洒”作为全部答案；补上枝干笔痕或羽片简化的证据。

## 第三次：把灰色拆开

选石墨与墨线小船。放大暗部，记录灰调由连续面还是密线形成，再缩小看整体。

**自查：**你能解释为何近看不同、远看却都显得灰吗？答案涉及尺度与密度，不需要材料鉴定。

## 第四次：只改两个旋钮

选蓝壶静物，写一套“保留体积，减少表面痕迹”的方案，再写一套“保留笔痕，降低背景对比”的方案。

**自查：**方案有没有具体位置和作用？“更干净”不够；“壶腹保留渐变，背景减少纹理”更清楚。

## 第五次：让方法搬家

把剪影猫的方法迁移到一个茶壶。画不出来也没关系，描述嘴、把手与壶腹之间的空隙。

**自查：**不加内部细节，轮廓还认得出吗？你在练识别线索，而不是画得像照片。

## 第六次：读一件真实作品

打开“真实作品旁读”里的一个馆藏链接。先看，再读标题与材料说明。找一处与本书示意接近的线索，再找一处明显不同的地方。

**自查：**不要要求原作符合本书模板。原作往往比入门图更复杂，差别正是你要发现的东西。

## 第七次：写一个能执行的简报

给雨中送书写一份五句需求：主要事件、情绪目标、视觉方法、必须保留的信息、允许变化的地方。使用“把偏好说清楚”中的模板，再按比较章节检查矛盾。

**自查：**是否同时要求极简、每处细节丰富、所有背景都抢眼？如果是，明确优先级。需求不是形容词越多越好。

## 用什么判断自己进步

| 等级 | 你能做到的事 |
| --- | --- |
| 开始 | 说出喜欢与不喜欢 |
| 观察 | 指出具体线、色、边或空间关系 |
| 比较 | 在同题材中分清方法与内容变化 |
| 解释 | 说明一个效果由哪些线索形成 |
| 迁移 | 把方法用于新题材并写成可执行要求 |

这不是考试，没有要求你认出每一个标签。能给判断提供证据，也能在证据不足时保留疑问，就已经具备继续欣赏图像的能力。
