# 把“我喜欢”说得更清楚

“文艺一点”“有高级感”“别太 AI”都是真实偏好，却不容易执行。把它们翻译成图像决策，你和创作者会轻松很多。

## 先拆开一句愿望

| 模糊说法 | 可观察的版本 |
| --- | --- |
| 水彩一点 | 透明薄层、保留纸白，背景边缘局部晕开 |
| 青春一点 | 自然笑容、轻快动作、舒展姿态、明亮环境 |
| 复古一点 | 限制色彩、选择具体印刷纹理与版面结构 |
| 手绘一点 | 指定排线、干笔、刀痕或笔触，并保留有方向的变化 |
| 不要太写实 | 简化形体与材质，明确比例、轮廓和阴影组织方式 |
| 更有故事 | 明确人物正在做什么，以及一个有意义的关系 |

## 一份可以直接填写的画面说明

```text
用途：封面／纪念图／故事插画／游戏素材
主角：谁，什么年龄与性格，保留哪些识别特征
动作：正在做一件什么具体的事
环境：哪些背景信息必须存在
构图：近景或全身；视觉焦点；留白的位置
造型：自然比例或概括形体；轮廓由线还是色块建立
明暗：区域阴影／连续体积／黑白块面／排线
颜色：主要色组；是否透明；是否有限色要求
质感：可见什么有方向的痕迹
风格主次：哪种方法负责整体，哪种负责局部
完成判断：缩小仍清楚；边缘规则一致；没有多余文字等
```

## 一个更换角色的示例

“画一位年长的花店店主，穿深蓝围裙，认真修剪一枝花；半身近景，手与花是第二焦点。采用彩铅般的方向性排线，脸部细致、背景疏朗。颜色以深蓝、暖灰与花的浅黄为主，纸纹可见，但不要用统一噪声覆盖所有区域。”

这份说明没有要求美少女，也可以有温暖与趣味。人物、动作、颜色、局部完成度和质感都能检查。

## 看结果时，不只问像不像

逐项对照要求：动作是否正确？焦点是否成立？所谓排线是否顺着形体？背景是不是抢走注意力？如果只有颜色接近，却没有方法特征，就先改方法，不必继续加风格形容词。

生成图也可能偶然很好看，却偏离教学目标。可以保留为融合示例，但在图注中写清楚偏差。例如“像素风插画，网格不统一”，比把结果硬说成严格像素艺术更有教育价值。
