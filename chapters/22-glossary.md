# 随手翻的词汇表

| 词 | 日常解释 | 可以看哪里 |
| --- | --- | --- |
| 明度 | 颜色有多亮或多暗 | 炭笔图的脸、围裙与窗口 |
| 饱和度 | 颜色有多鲜明或偏灰 | 鼓手的橙蓝与水彩的浅色 |
| 冷暖 | 颜色之间偏蓝绿或偏红黄的关系 | 油画袖口的黄与蓝紫 |
| 固有色 | 暂不考虑光照时，物体被认为本来的颜色 | 蓝裙在不同画法中的变化 |
| 轮廓线 | 描述外缘的线 | 漫画图人物边缘 |
| 硬边 | 变化突然、边界清楚 | 赛璐璐袖子阴影 |
| 软边 | 变化渐缓、边界不那么清楚 | 水彩背景 |
| 失边 | 局部轮廓融入相邻区域 | 水彩衣服与背景的一些交界 |
| 块面 | 用较大颜色形状组织图像 | Gouache 树叶 |
| 排线 | 多条线一起形成形、色调或质感 | 彩铅头发与衣服 |
| 交叉排线 | 多组不同方向的线重叠 | 彩铅类塑形练习 |
| 留白 | 有意保留的空白区域 | 水墨人物右侧 |
| 飞白 | 笔痕中断续露出底色的外观 | 水墨裙摆 |
| 厚涂 | 较厚颜料层与可见笔痕的方法 | 油画风插图仅模拟其外观 |
| 透明叠色 | 下面的色层仍参与最后颜色 | 水彩裙子 |
| 覆盖 | 上层较不透明地遮住下层 | Gouache 的浅色笔触 |
| 凸版 | 保留的凸起表面承接油墨的版画方式 | 木刻工艺说明 |
| 色版 | 分别负责某种颜色的制版层 | 浮世绘与 Riso 章节 |
| 套准 | 不同色版按预定位置对齐 | Riso 的局部错位讨论 |
| 网点 | 规则点阵参与色调或印刷效果 | 复古漫画脸颊 |
| 负空间 | 物体之间或周围的空隙形状 | 新艺术的花叶间隙 |
| 多视点 | 同图整合不同观看方向 | 立体主义人物的脸 |
| 二值 | 主要以两种亮暗状态组织图像 | 黑白木刻风 |
| 像素簇 | 一组像素共同表达一个形状 | 像素风树叶与裙子 |
| 视觉焦点 | 最希望观者先看的地方 | 各图脸部或关键动作 |
| 简化 | 有选择地删减信息，保持要点 | 木刻剪影、漫画块面 |

| 凹版 | 油墨保留在版面凹处再转印 | 蚀刻章节 |
| 印版痕 | 印刷压力与版边可能留在纸上的痕迹 | 本书蚀刻图只模拟矩形边界 |
| 纸齿 | 纸面能留住粉粒的细微起伏 | 色粉章节 |
| 黏结材料 | 把颜料连在一起并附着到底材的成分 | 蛋彩、丙烯的材料说明 |
| 固有色之外的色 | 不按对象通常颜色安排的色彩 | 野兽派蓝紫树干 |
| 点色并置 | 小色点相邻而非先在调色盘完全混匀 | 点彩街景 |
| 剪影 | 内部细节压缩，主要靠整体外轮廓识别 | 深蓝窗边猫 |
| 拼贴接缝 | 不同碎片相接或叠放的边界 | 混合拼贴猫 |
| 分格 | 把连续故事划成若干画面 | 三种送书漫画 |
| 景别 | 镜头离对象远近的取景范围 | 街道远景与手部近景 |
| 视觉节奏 | 信息、空白与强弱变化造成的阅读步调 | 纵向漫画间隔 |
| 构形 | 线、点、块怎样共同建立对象的形 | 点彩、墨线与剪纸 |

词汇是工具，不是考试。若能用“袖子阴影边缘很清楚”解释，就不一定要先说“硬边”。
