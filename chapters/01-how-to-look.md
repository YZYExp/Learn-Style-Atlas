# 五个问题，看懂一张画

先别问“这是什么派”。把图缩小，停三秒，再按下面五个问题看。你会发现，许多陌生名字背后的差别其实很具体。

## 1. 轮廓是谁画出来的？

漫画常用线条把人物从背景中分开。油画可以没有外轮廓线，靠相邻色块的明暗差让手臂出现。水彩有时让轮廓消失一段，观者仍能补出形状。

用手指沿衣服外缘走一圈：哪里有线？哪里只靠颜色？哪里融进了背景？边缘的清楚和模糊不是同一回事，也不等于画得认真或随便。

## 2. 阴影是块，还是渐变？

赛璐璐常把亮面与暗面分成几块；写实绘画会安排更连续的变化；木刻可以用白线的密度表现灰度，却不用真的灰色。看鼻梁、袖口和裙褶，最容易找到答案。

“平面”也不表示没有空间。一个有清楚遮挡关系的小色块，同样能让你看出手臂位于身体前面。

## 3. 颜色在描述物体，还是描述感受？

蓝裙可能是裙子本来的蓝，也可能是用冷色让人物显得安静。表现主义图中的蓝色皮肤更强调情绪。看颜色是否随光线合理变化，是否有明显违背自然色的安排。

暖色常让人想到火、太阳或亲近感，但不能把它当作跨情境的固定心理公式。大面积橙色也可能令人紧张，关键要看对比、面积和题材。

## 4. 空间服从哪种规则？

路越远越窄，可能采用单一观看位置的透视。立体主义可以把正面与侧面拼在同一物体中。装饰插画则可能为了图案节奏，压平背景。问：“如果我真的站在这里，能同时看见这些东西吗？”

## 5. 表面有什么痕迹？

排线、晕染、笔触、刻痕、网点、像素阶梯——这些都是方法留下的视觉线索。AI 可以模拟它们，所以痕迹只能帮助你描述外观，不能直接鉴定制作工艺。

## 一张观察卡

| 维度 | 你可以写什么 |
| --- | --- |
| 线与边缘 | 细线／粗线／无外线／局部消失 |
| 明暗 | 几块阴影／连续变化／黑白二值／排线 |
| 色彩 | 透明叠色／不透明覆盖／限色／非自然色 |
| 空间 | 单一视点／多个视点／压平／不可能关系 |
| 质感 | 纸纹／颗粒／笔触／刀痕／网点／像素 |

**小练习：**不说风格名字，用以上五项介绍一张图。若别人仅凭你的描述就能从三张图中认出它，你的观察已经足够具体。
