# 看懂画风：一场有趣的插画旅行

给喜欢看图、想说清楚自己喜欢什么的人。

这里是一部用 Markdown 写作、用 Git 管理的图解书。第一版包含 16 个风格专题，以及观察入门、比较实验、选风格指南、小游戏和词汇表。所有章节均已写成正文；未来扩充计划单独存放，不混入成稿。

## 从哪里开始

- [完整目录](SUMMARY.md)：逐章阅读。
- [导读：先看图，再学名字](chapters/00-preface.md)：理解本书的玩法。
- [五个问题，看懂一张画](chapters/01-how-to-look.md)：建立观察习惯。
- `build/book.md`：合并后的完整 Markdown 书稿。
- `build/index.html`：离线阅读版，图片已内嵌，可直接用浏览器打开。

## 读者约定

本书插图是 AI 生成的教学示意，不是真实手绘、木刻或印刷品。我们讲的是图像模拟出的视觉语言；涉及颜料、纸张、制版和历史时，会区分真实工艺与模拟效果。生成结果偏离目标时会直接指出，不把标签当作鉴定结果。

第一组十张保留相近人物与服装，方便对照。第二组开始更换年龄、人物、职业与场景，避免把某种风格误认成某一种脸。

## 文件怎么组织

| 路径 | 内容 |
| --- | --- |
| `chapters/` | 分章 Markdown 正文，唯一书稿来源 |
| `assets/images/` | 阅读用插图，稳定编号 |
| `assets/originals/` | 原始生成 PNG，保留完整分辨率 |
| `assets/manifest.json` | 插图题材、来源、校验值、生成记录与评价 |
| `editorial/` | 写作规范、资料来源、进度、后续计划 |
| `scripts/` | 合并、离线阅读版构建与链接检查 |
| `build/` | 可重新生成的阅读产物，不纳入 Git |

## 构建与检查

```bash
python3 scripts/build.py
python3 scripts/check.py
```

构建使用 Python 标准库；生成阅读图片使用 Pillow，书稿阅读本身不依赖 Python。Git 历史保存在交付仓库中，不绑定任何远端账户。新一轮增补先改分章正文与插图清单，再运行检查、构建并提交。

当前版本：v0.1，2026-10-06。范围是第一卷的完整入门稿，不声称覆盖全部艺术风格。
