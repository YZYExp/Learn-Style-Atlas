# 看懂画风：一场有趣的插画旅行

中文图解入门书，写给喜欢看图、想说清楚自己喜欢什么的人。全书已完本，定稿版本 v1.0，2026-10-06。

全书包含 35 个独立配图专题、14 组横向比较、同故事三种漫画案例，以及观察方法、材料辨别、选画法、需求写作、七次学习路线、小游戏、误判练习、词汇表与真实作品旁读。51 个正文单元和资料附录全部写成正文，没有占位章节。

## 阅读入口

- [完整目录](SUMMARY.md)：按全书顺序逐章阅读。
- [导读](chapters/00-preface.md)：理解图像、标签与证据的关系。
- [同题材实验室](chapters/45-comparisons.md)：用花鸟、街角、小船、猫和静物练比较。
- [同一雨天的漫画案例](chapters/46-comic-story.md)：看镜头与间隔怎样讲故事。
- `build/book.md`：整本合并 Markdown，图片路径指向本仓库。
- `build/index.html`：独立离线阅读版，图片内嵌，点击可放大，支持明暗切换。

## 图像与资料约定

全部插图为 AI 生成教学示意。书中区分可见外观与真实材料，不声称模拟纹理证明某种制作工艺。偏离目标的图像在对应章节直接说明。馆方资料与制造商说明只支持相应事实，具体图像判断和练习答案属于编辑解读。

本书是一部完整入门书，不是穷尽全部历史流派的百科全书。名称之间允许交叉，地区漫画名称也不代表整个地区只有一种画法。

## 构建与检查

```bash
python3 scripts/build.py
python3 scripts/check.py
```

构建与检查使用 Python 标准库，打开 HTML 不依赖 Python。阅读 JPEG 的制作使用 Pillow；原图不被重采样覆盖。

交付 ZIP 保留 Git 全部历史、v0.1 入门稿标签与 v1.0 定稿标签，不绑定远端账户。`build/` 不纳入 Git，但收入交付 ZIP，保证开箱可读。归档的旧路线图只是版本史，不是正式书稿的未完成承诺。
